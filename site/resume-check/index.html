检查规则

规则判定
contact-missing没有任何联系方式 → error（电话/邮箱/微信/Email；只写一个邮箱地址也算）
email-invalid邮箱过不了严格形态（连续点、域缺尾）→ error，报行号；检测宽松、验证严格，坏地址必被检出
phone-invalid电话位数不在 7-15 位 → error，报行号
dates-overlap两段经历时间重叠 → error，报两段区间
dates-order一段封闭经历开始于「至今」之后 → error（真矛盾，不是文档顺序问题）
date-gap两段之间空窗 >12 个月 → warn，仅 --no-allow-gaps 时判
education-missing没有教育/学历段 → warn

用法

npx resume-check resume.md --json
npx resume-check resume.md --no-allow-gaps

这是清单，不是专业人士。合同检查不是法律意见，发票检查不判税务合规，listing 检查不判商业价值。每条发现都是文本里可判定的结构缺陷，带行号。
