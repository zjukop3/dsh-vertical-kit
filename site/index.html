DSH VERTICAL KIT

行业场景交付检查

Agent 已经产出结果、行业里的人准备接手的那一刻，这三个检查各自决定一件事：合同是否结构可审、发票算术是否成立、商品导出是否可上架。每个都是单个命令，从文件本身判定。

检查清单npm 包搜索名词它决定什么
合同结构检查清单dsh-agreement-check合同检查 / 合同审查清单这份合同在结构上是否可审
发票字段检查清单dsh-invoice-check发票检查 / 发票校验发票上能从文本判定的算术与格式是否成立
电商商品信息检查清单dsh-listing-check电商商品信息检查 / listing 检查商品导出表是否达到可上架的结构卫生

定位

护城河不在深度——专业产品随时碾压深度。在：离线可跑、出口码接 CI、免费、host 路由与 CLI 调同一函数。定位是「专业人士的前五分钟」，不是「专业人士的替代」。通用的五个检查（哈希/引用/结构/表格/数字）在 dsh-verify-kit。
